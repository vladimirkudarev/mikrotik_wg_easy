# Decisions

## Принятые вводные

- Минимальная версия RouterOS: `7.21+`.
- Транспорт управления: SSH из контейнера к RouterOS.
- Размещение: только контейнер на MikroTik.
- Целевые архитектуры контейнера: `arm64` и `arm/v7`.
- Client private keys/config можно хранить для повторного показа QR.
- Дефолтный сценарий: full-tunnel `0.0.0.0/0`.
